Revenge · Kettu · Vendetta-compatible plugin

Local Edit
Remastered

Change how another person's message appears on your device. Local edits are saved on this device only; they are not sent to Discord and other people cannot see them.

Install

  1. Open Discord with Revenge, Kettu, or a compatible Vendetta-based client.
  2. Go to the client's Plugins page.
  3. Copy the install URL below and paste it into the plugin installer.
  4. Long-press another person's message and select Edit Locally.
View manifest Source code

Install URL: https://lesbunny.github.io/revengeplugin/localedit/

If the edit does not appear after a Discord update, disable and re-enable the plugin and check the source repository for compatibility fixes.
